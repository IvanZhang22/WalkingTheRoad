# v2.2.5：多模态验收与部署

## 一、最终能力边界

| 输入 | Provider | 证据定位 | 自动进入 W3 的条件 |
|---|---|---|---|
| TXT / MD / DOCX | 本地解析 | 字符区间 | 解析成功 |
| 文字型 PDF | 本地解析 | 页码与字符区间 | 解析成功 |
| MP3 / WAV | 阶跃文件 ASR | 分句毫秒时间戳 | 不自动；官方无置信度，需人工复核 |
| MP3 / WAV / M4A / WEBM | Deepgram Nova-3 | 分句毫秒时间戳 | 分句置信度不低于 0.8 |
| PNG / JPG / JPEG / WEBP | 百度 OCR | bbox | 行置信度不低于 0.8 |
| 扫描 PDF | 百度 OCR | 页码与 bbox | 行置信度不低于 0.8 |

所有附件仍经统一安全下载器校验。视频、base64、data URL、本地路径和私网 URL 不在
本版范围内。

官方接口依据：

- [阶跃音频文件识别](https://platform.stepfun.com/docs/zh/api-reference/audio/asr)
- [Deepgram Pre-Recorded Audio](https://developers.deepgram.com/reference/speech-to-text/listen-pre-recorded)
- [Deepgram Utterances](https://developers.deepgram.com/docs/utterances)
- [百度 PP-OCRv6](https://cloud.baidu.com/doc/OCR/s/6mncwkr9c)

## 二、推荐演示配置

若目标是演示“上传音频后自动生成带核验引文的主题报告”，文本模型使用 OpenRouter
免费模型路由，音频使用 Deepgram。这样不需要 StepFun 账号或 Vercel 绑卡，同时保留时间戳和置信度：

```dotenv
APP_MODE=live

MODEL_PROVIDER=openrouter
MODEL_API_KEY=
OPENROUTER_API_KEY=<OpenRouter Key>
MODEL_BASE_URL=https://openrouter.ai/api/v1
MODEL_NAME=openrouter/free
MODEL_THINKING=disabled

AGENT_API_KEY=<单独生成的长随机字符串>

ASR_PROVIDER=deepgram
DEEPGRAM_API_KEY=<Deepgram Key>
DEEPGRAM_BASE_URL=https://api.deepgram.com
DEEPGRAM_MODEL=nova-3
DEEPGRAM_LANGUAGE=zh-CN
DEEPGRAM_DIARIZE_MODEL=latest
DEEPGRAM_TIMEOUT_SECONDS=120

OCR_PROVIDER=baidu
BAIDU_OCR_API_KEY=<百度 OCR AK>
BAIDU_OCR_SECRET_KEY=<百度 OCR SK>
BAIDU_OCR_BASE_URL=https://aip.baidubce.com
BAIDU_OCR_ENDPOINT_PATH=/rest/2.0/ocr/v1/pp_ocrv5
BAIDU_OCR_TIMEOUT_SECONDS=60
BAIDU_OCR_MAX_PAGES=20
```

执行 `python scripts/connect_openrouter_oauth.py` 后，只需在浏览器完成一次 OpenRouter 授权；
脚本会把密钥直接写入 Vercel Production/Preview，不会输出或保存明文 Key。免费模型适合演示和
低频试用；处理真实敏感材料前，应关闭输入输出日志、禁止路由到会训练数据的 Provider，并改用
数据政策明确的稳定模型。

只演示音频时，百度三项可以不配并把 `OCR_PROVIDER=disabled`。只演示图片/PDF 时，
可以把 `ASR_PROVIDER=disabled`。截图中曾出现过的阶跃 Key 必须先撤销，不能继续使用。

## 三、Vercel 配置

1. 在 Vercel 项目 `Settings → Environment Variables` 中逐项添加上面的非空变量；
2. 变量至少应用到 `Production` 和本次使用的 `Preview`；
3. 不要把 `.env` 上传到 Vercel，也不要把供应商 Key 写进 `vercel.json`；
4. 仓库已启用 Fluid compute，并把 Python Function 最长执行时间设为 300 秒，以容纳
   下载、ASR/OCR 和 W3 两次模型调用；
5. 合并最终 PR 后重新部署；
6. 访问 `https://<部署域名>/api/health`，至少确认：

```json
{
  "status": "ok",
  "version": "2.2.0",
  "key_configured": true,
  "agent_key_configured": true,
  "asr_provider": "deepgram",
  "asr_key_configured": true,
  "ocr_provider": "baidu",
  "ocr_key_configured": true
}
```

健康检查只显示布尔状态，不返回任何 Key。

## 四、部署后直接 API 验收

先用一个无隐私、可公开下载的短音频 URL：

```powershell
$agentUrl = "https://<部署域名>"
$agentKey = "<AGENT_API_KEY>"
$audioUrl = "https://<公开临时地址>/demo.mp3"

$body = @{
  model = "xingxiaodao-agent"
  messages = @(
    @{
      role = "user"
      content = @(
        @{
          type = "text"
          text = "研究问题：学生如何理解学校就业服务入口的可达性？请做主题分析。"
        },
        @{
          type = "input_audio"
          input_audio = @{url = $audioUrl; format = "mp3"}
        }
      )
    }
  )
} | ConvertTo-Json -Depth 8

Invoke-RestMethod `
  -Method Post `
  -Uri "$agentUrl/v1/chat/completions" `
  -Headers @{Authorization = "Bearer $agentKey"} `
  -ContentType "application/json; charset=utf-8" `
  -Body ([Text.Encoding]::UTF8.GetBytes($body))
```

通过标准：响应同时包含 `W3 质性材料分析`、材料预检统计和完整主题报告；响应不得
出现附件 URL、签名参数、Deepgram Key 或模型 Key。

## 五、清小搭字段映射

清小搭应把上传文件产生的公网临时 URL 映射为同一个大模型节点的消息 content：

| 清小搭字段 | Chat Completion 字段 |
|---|---|
| 用户填写的研究问题 | `messages[0].content[0].text` |
| 上传音频公网 URL | `messages[0].content[1].input_audio.url` |
| 音频扩展名 | `messages[0].content[1].input_audio.format` |
| Agent 地址 | `https://<部署域名>/v1` |
| 模型名 | `xingxiaodao-agent` |
| 鉴权 | `Authorization: Bearer <AGENT_API_KEY>` |

清小搭工作流里不再创建 Deepgram、阶跃或百度工具节点，也不保存这些厂商密钥。

已知限制：此前实测清小搭服务端无法访问境外 Vercel。若连通性测试仍失败，不是请求
Schema 或多模态代码错误；应把同一仓库部署到国内可公开访问的 HTTPS 服务，再把
清小搭的 Agent 地址替换为国内地址。该网络迁移属于 v2.3。

## 六、无费用质量门

```powershell
$env:APP_MODE='mock'
python scripts/run_quality_gate.py
```

其中 `tests/test_multimodal_chat_e2e.py` 使用 Deepgram 真实响应结构的本地假响应，验证
同一端点完整跑过下载、ASR 归一化、置信度门控、W3 提取、精确引文核验和主题生成；
它不会联网、不会读取真实 Key，也不会产生费用。

真实供应商验收不进入 CI。团队只使用脱敏短样本人工执行一次，并记录日期、Provider、
模型、耗时、材料状态和是否出现时间戳/bbox；不要保存原始 URL 查询参数或完整正文。

音频或图片会由服务端发送给所选 ASR/OCR 厂商处理。上传前必须完成必要的知情同意和
脱敏，确认团队接受对应厂商的数据处理条款；保密访谈、身份证件和未授权人脸材料不得
用于演示。

## 七、回滚

最终 PR 内部按能力拆成独立提交。出现问题时优先用环境变量关闭单个能力：

```dotenv
ASR_PROVIDER=disabled
OCR_PROVIDER=disabled
```

这样普通文本和文档工作流仍可使用。若需整体回滚，回退最终 v2.2 PR 的合并提交，
重新部署 v2.1.0；不要删除项目、环境变量历史或使用破坏性 Git 命令。
