# 行小道文档索引

当前线上能力以根目录的 [README](../README.md) 与健康检查中的版本号为准。当前开发版本为 **v3.4.4**。

## 当前部署与使用

- 清小搭接入：OpenAI 兼容的 `/v1/models` 与 `/v1/chat/completions`；
- 音频：后台切分、转写、抽样核对与后台材料分析；
- 图片、扫描件：百度 OCR；文档：Word、PDF、表格和文本；
- 项目卡：同一清小搭会话内保存项目进度与已确认信息。

## 历史文档

文件名带 `v1`、`v2`、`v3.0` 或 `v3.1` 的文档均为**版本归档和决策记录**，不代表当前可部署能力；保留它们是为了追溯设计过程，而不是作为部署说明。

部署时只使用 `8-云服务器部署-8.14` 中与目标版本同名的压缩包和 `upgrade-*.sh` 脚本。
