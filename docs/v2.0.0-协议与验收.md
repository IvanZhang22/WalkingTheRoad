# 行小道 v2.0.0：OpenAI 兼容协议与本地验收

## 一、版本范围

v2.0.0 解决“清小搭能否把行小道识别为一个合规的对端 Agent 服务”。本版只接收文本 `messages[].content`，不接收音频、文件 URL 或 base64；这些内容属于 v2.2.0。

## 二、公开契约

```text
GET  /v1/models
POST /v1/chat/completions
Authorization: Bearer <AGENT_API_KEY>
```

模型 ID 固定为 `xingxiaodao-agent`。`model` 可省略、为空或为该 ID；当前不把用户指定的模型名称转发给阶跃星辰。

聊天端点读取最新一条 user 消息，调用既有意图识别器并输出 W1—W4 的建议与缺失信息。它不复制第二套业务 Prompt，也不依赖本地页面的后台轮询流程。

## 三、鉴权和密钥边界

| 密钥 | 作用 | 出现位置 |
|---|---|---|
| `AGENT_API_KEY` | 清小搭或调试客户端调用行小道 | 请求 `Authorization: Bearer ...` 与 Vercel 环境变量 |
| `MODEL_API_KEY` | 行小道调用阶跃星辰或备用模型 | 仅服务端环境变量 |

缺失、错误或格式不正确的 Agent 密钥一律返回 401；服务端未设置 `AGENT_API_KEY` 返回 503。健康接口只暴露是否已配置，不返回密钥内容。

## 四、流式与探测

`stream: true` 时，输出顺序固定：assistant role 帧 → content 帧 → stop + usage 帧 → `data: [DONE]`。清小搭的最小探测常用 `max_tokens: 1`；本服务在该情况下立即返回“行小道服务正常”，不消耗模型调用。

## 五、本地验收

在 `.env` 添加一个只用于本地测试的 `AGENT_API_KEY` 后启动服务：

```powershell
.\.venv\Scripts\python.exe -m pytest tests\test_openai_compat.py
```

验收覆盖：错误密钥、模型列表、W3 路由的非流式响应、SSE 完整终止、探测响应和非字符串 content 的拒绝。全量门禁仍使用：

```powershell
.\.venv\Scripts\python.exe scripts\run_quality_gate.py
```

## 六、明确不做

- 不把 `AGENT_API_KEY` 提交到 Git；
- 不在本版把内存 RunStore 当成云端会话数据库；
- 不支持 `input_audio`、`file`、`x_soda.attachments`；
- 不在未部署前声称清小搭已接入成功。
